## Game screens

### Map screen

The map screen shows the squad moving around. Locations are highlighted.

* Pins for each squad.
* Markers for locations.
* Markers for wandering hordes.
* Option to select squads, and move them to locations, or an arbitrary position to explore.

### Location screen

Types of locations:
* fixed: always there, always the same, possibly used in story.
* static: randomly generated structures, like houses or gas stations.
* temporary: revealed by events, like a forest clearing, or the middle of the road.

Options:
* Manage location inventory: an inventory list is kept for the location, where
characters can store gear.
* Clear: check the location for enemies
* Scavenge: Search for supplies.
* Make camp: Squad gains access to camp options while in the location screen
  * basic survival: make campfire, cook, set traps
  * rest and recuperate
* Make base: set up sleeping area, workstations, storage, necessities, etc.
* Set or check snares
* Build or maintain defenses

### Character screen

* Inventory
* Name, portrait, appearance, stats, xp, level
* Traits
* Afflictions: wounds, cuts, bruises
* Condition: hunger, thirst, fatigue
